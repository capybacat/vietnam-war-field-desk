# Field Desk artwork

The app emblem was generated using the built-in ImageGen tool for this project. The original PNG has a transparent background. `app.ico` packages the same artwork as seven Windows icon sizes: 16, 24, 32, 48, 64, 128 and 256 px. The emblem and icon are embedded in the EXE; the Assets folder is needed only for rebuilding and reuse.

The interface is a stylised interpretation of olive-drab field equipment and printed operations paperwork. It is not a reproduction of an actual historical computer or official unit insignia.

## Final generation prompt

Use case: logo-brand. Asset type: Windows desktop app icon and matching small header emblem for a Vietnam War game live editor named Field Desk. Create a single square app emblem, centered, with genuinely transparent space outside the emblem. Design: a compact rounded-square olive-drab enamel field-equipment badge, a bold warm-ivory silhouette of a Vietnam-era UH-1 Huey helicopter in profile facing right, a small muted amber sunset disc behind the cabin, and two very simple ivory chevron/radio marks below. Style: elegant 1960s military screen-print, restrained light wear on the outer rim, flat high-contrast large shapes, sharply legible at 32px and 64px. Palette only deep jungle green, olive drab, warm ivory, muted amber. Entire emblem fits within an 85% square safe area. Straight-on orthographic view, no perspective mockup, no cast shadow outside, no text, no lettering, no flags, no real military insignia, no watermark, no extra objects. The helicopter must be readable and not cropped. This is a production app icon, not an illustration or photograph.
